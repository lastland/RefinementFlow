# Triage Labels

The skills use five canonical triage roles. For this local Markdown tracker, record the corresponding value in a `Status:` line near the top of each issue file.

| Canonical role | Status value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified; an agent can implement it without more human context |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill says to apply a triage label, set the issue's `Status:` line to the corresponding value from this table.

Edit the Status value column to change the vocabulary.
